# 段階1：議事録をAIに読ませる

GitHubもCloudflareも使いません。AI（Claudeなど）だけで始められます。

## やること

1. 自分の議会の会議録検索で、自分の発言を開く
2. 自分の質問と、それに対する答弁の部分だけをコピーする（会議1回分で十分）
3. テキストファイルに保存する。**1行目に、その会議録のURLを貼る**
4. AIに、そのファイルを渡して頼む

## 頼み方の例

```
このファイルは、私（〇〇議会議員）の議会での発言と、それに対する答弁です。
1行目は会議録のURLです。
論点ごとに、次の形で整理してください。
・何を質問・提案したか
・行政は何と答えたか
推測で埋めず、ファイルに書いていないことは書かないでください。
```

慣れたら、「過去に〇〇について何を質問したか教えて」のように聞くこともできます。

## 気をつけること

- 入れるのは、公開済みの会議録だけ。市民からの相談や個人情報は入れない
- AIの整理には誤りや抜けがあります。必ず元の会議録と見比べる
- AIの説明が長すぎたら、「一度に1つだけ教えて」と返す
