# 困ったときのプロンプト

下の枠の中をそのままClaudeなどのAIに貼り、`[ ]` の部分を書き換えてください。  
今の画面のスクリーンショットも一緒に渡すと、答えが正確になります。個人情報や秘密情報が写っていないことを、送る前に確認してください。

```text
私はプログラミングの初心者です。
地方議員として、自分の議会活動の記録を、検索できるサイトにする作業をしています。

いまやろうとしていること：[例：GitHubに最初のファイルを置く]
いまの状態：[例：「Upload files」を押したら、エラーが出た]
表示されたメッセージ：[秘密情報を除き、エラーの文面をそのまま貼る]
使っているもの：[例：Windows、Chrome、Claude Pro]

お願い：
- 一度に複数の操作を指示せず、次に行う操作を1つだけ教えてください
- 私が結果を返したら、それを確認してから次に進んでください
- 分からないことを推測で埋めず、分からないときは「分からない」と言ってください
- 会議録サイトをプログラムで自動取得する方法は提案しないでください
- 会議録の原文・全文・PDF・ZIPや、大量の本文断片をGitHubへ置かせないでください
- パスワード、APIキー、トークン、個人情報、非公開資料を、AIや公開GitHubへ貼らせないでください
```

## うまくいかないとき

- 同じ会話が長くなったら、新しい会話を始めて、このプロンプトから貼り直す
- 手順書がある場合は、ファイルとして添付して「この手順書に従って」と書き添える
- 3回やってもうまくいかなければ、[Discussions](../../../discussions)で過去の質問を探す
- 解決しない場合は、個別DMではなく、秘密情報を除いて[公開Q&A](../../../discussions/categories/q-a)へ投稿する
