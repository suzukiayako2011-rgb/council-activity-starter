# 議会活動の記録をためて使う：全体像（暫定）

HPを作ることだけが目的ではありません。自分と市民が記録をたどり、次の質問や説明に使えるようにする取り組みです。[現在地から選ぶ](../README.md#自分の現在地から選ぶ)ところへ戻って、自分の次の作業を1つ選んでください。

| 段階 | やること |
|---|---|
| ① 集める | 公開済みの自分の質問・提案と答弁・回答、公式URLを集め、原資料は手元に保存する |
| ② 整理する | AIで論点ごとに整理し、[starter-0.1](データの形_暫定版.md)の形に揃える |
| ③ 確かめる | 原資料と照合し、論点・答弁・出典・判定を人が確認する |
| ④ ためる | 恒久IDを付け、同じ形で記録を増やす |
| ⑤ 公開する | [公開テスト](公開テスト.md)で公開と更新を試し、確認済みの記録を検索サイトへ載せる |
| ⑥ 探して使う | 過去の質問を検索し、市民への説明や次の議会活動に使う |
| ⑦ その後を記録する | 資料で確認できた市の動きを、follow_upに出典URL・確認日付きで残す |
| ⑧ 改善する | 過去分の追加、検索や表示の改善、仕様変更時の変換を進める |

**③の確認は一度で終わりません。** データを増やす・直すたびに行います。⑦の後年情報だけで、当時の対応状況を上書きしません。

独自ドメインの接続や既存HPとの統合は、HP業者に確認してから進めてください。[安全と表現のルール](../README.md#はじめる前に必ず確認すること)を確認し、困ったことは[公開Q&A](../README.md#困ったときの順番)に残してください。
