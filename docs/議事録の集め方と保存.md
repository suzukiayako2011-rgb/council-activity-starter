# 議事録の集め方と保存

## 最初に確認すること

**一番よいのは、議会事務局から、自分の発言を含む会議録データをまとめて提供してもらうことです。** 質問・質疑だけでなく、それに対する答弁も含む、会議ごとのデータを受け取れると、後の整理が最も確実です。集める手間がなくなり、写し間違いも起きません。前例がなく、時間がかかることもあるので、依頼は早めに出しておき、待つ間は下の方法で進めてください。提供を受けたときは、利用の条件や公開できる範囲も確認します。

会議録を**プログラムで自動取得してよいか**も、議会ごとに違います。議会事務局や、会議録検索システムの利用規約で確認してください。確認できるまでは、次の「人が集める」方法で進めてください。

## 人が集める方法

1. ブラウザで会議録を開き、自分の質問と答弁の部分をコピーする
2. テキストファイルに保存し、**1行目に会議録のURLを貼る**
3. ファイル名は「日付_会議の種類」にする（例：`2026-06-12_本会議_一般質問.txt`）
4. 同じ日に複数あるときは、末尾に `_b` などを付ける

## 保存のルール

- **コピーした原文は消さずに、手元に保存しておく。** 後で整理の基準を変えたときに、集め直さずに済みます
- **原文は GitHub に置かない（公開・非公開とも）。** 手元のパソコンか、自分だけが見られる場所に保存します
- 公開するデータには、原文ではなく、会議録のURLを載せます
- 作業用のフォルダを1つ決めて、そこにまとめる

## AIに伝えておくこと

AIに作業を頼むときは、最初にこう伝えておきます。

```
会議録検索システムのページを、プログラムで取得・閲覧しないでください。
会議録のURLは、文字列として記録するだけにしてください。
```
