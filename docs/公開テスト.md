# 公開テスト：1ページを公開して、翌日に直す

議会活動の記録を作る前に、**公開の仕組みを自分で回せるか**だけを試します。中身は仮のページで構いません。

## 用意するもの

- GitHubアカウント、Cloudflareアカウント（どちらも無料で作れます）
- このリポジトリの `starter/` フォルダ（`public/index.html` と `wrangler.jsonc`）

## 1日目（目安：3時間）

1. GitHubに、自分用のリポジトリを作る
2. `starter/` の中身を、そのリポジトリに置く（`wrangler.jsonc` は一番上、`index.html` は `public` フォルダの中）
3. `wrangler.jsonc` の `name` を、自分用の名前（半角英数字とハイフン）に書き換える
4. Cloudflareで、そのGitHubリポジトリをつないで公開する
5. 表示された仮のURLを開き、ページが見えたら成功

画面の文言が手順と違うときは、**この手順書とスクリーンショットをAIに渡して**、「次にやることを1つだけ教えて」と頼んでください。

## 2日目（目安：30分）

1. `index.html` の文章を1か所だけ直す
2. もう一度公開し、変更が反映されたか確かめる

**初回にたまたま通ることより、翌日もう一度自分でできることの方が大事です。** ここまでできたら、公開テストは終わりです。

## 注意

- 雛形の `index.html` には、検索エンジンに載せない指定（`noindex`）が入っています。テスト用だからです。**本番のページにするときは、必ず外してください**
- パスワードやAPIキーを、ファイルやAIとの会話に書かないでください
