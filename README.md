# 議会活動の記録をAIで公開する — 始め方とQ&A

自分が議会で何を質問し、行政が何と答え、その後どうなったか。  
これを、自分自身も、市民も、AIも検索できる形で残すための、始め方と質問の場です。

プログラミングの知識は前提にしていません。作業はAI（Claudeなど）に日本語で頼みながら進めます。

- 実例：[三神たかし議会活動データベース](https://mikami-takashi.net/archive.html)
- 実例：[出雲けいこ議員の議会活動の記録](https://izumokeiko.com/record)

> このリポジトリはスターターキット兼、公開Q&Aの場所です。手順書と雛形は順次追加します。

## 自分の現在地から選ぶ

**迷ったらまず → [まずここから：実践マニュアル](docs/まずここから_実践マニュアル.md)**（やること・AIに貼る文・確認・完了条件を順に案内します）

全員が同じ順番で進む必要はありません。できているところの次から選んでください。

| 現在地 | 次にやること | 資料 |
|---|---|---|
| 段階1：まだ記録を整理していない | 議事録1件をAIで整理し、原文と見比べる | [段階1](docs/段階1_議事録をAIに読ませる.md) |
| 段階2：1件整理できた | starter-0.1に合わせて数件を同じ形で保存する | [データの形（暫定版）](docs/データの形_暫定版.md)・[架空の見本JSON](examples/starter-0.1.json)・[JSON Schema](examples/starter-0.1.schema.json) |
| 段階3：同じ形の記録がたまった | GitHub／Cloudflare等で検索サイトとして公開する。まず公開と更新を試す | [公開テスト](docs/公開テスト.md)（雛形：`starter/`） |
| 段階4：既に公開できている | 過去分を追加する、検索を改善する、出典と確認日付きのfollow_upメモを追加する | [暫定仕様とメモの書き方](docs/データの形_暫定版.md)・[表現ルール](#はじめる前に必ず確認すること) |

段階1だけでも役に立ちます。全員が公開まで進む必要はありません。[議事録の集め方と保存](docs/議事録の集め方と保存.md)、[全体像](docs/全体像.md)も参照してください。

公開テストの雛形は1ページの仮サイトです。検索画面の雛形は今後追加します。独自ドメインの接続や既存HPとの統合は、HP業者に確認してから進めてください。設定によってHPやメールに影響する場合があります。

三神たかしの公開DB／サイトは新しい「実施済」基準への移行監査中で、既存値・表示には旧基準が残っています。新規データは暫定仕様に掲載した定義で判定してください。

## はじめる前に、必ず確認すること

| 項目 | 内容 |
|---|---|
| 会議録の利用ルール | 会議録の自動取得が認められているかどうかは、自治体ごとに違います。**ご自身の議会事務局や利用規約で確認してください。** 確認できるまでは、人がブラウザで開いて必要な範囲を扱い、出典URLを記録する方法で進めてください |
| GitHubに置かないもの | 会議録の原文・全文・PDF・ZIPや、大量の本文断片は置かないでください。必要な情報を構造化し、原文は公式サイトのURLで参照します |
| AIや公開Q&Aに入れないもの | 市民からの相談内容、個人情報、非公開資料、パスワード、APIキー、トークンなどの秘密情報は入力・投稿しないでください |
| 費用 | GitHubとCloudflareは、現時点では無料で始められる範囲があります。AIの有料プランや利用枠、各サービスの料金・条件は変更されるため、開始時に公式情報を確認してください |
| 判定の責任 | 「対応状況」などはAIに候補を出させることはできますが、確定するのは議員本人です。第三者の検証を経ていない場合は、その旨をサイトに明記してください |
| 表現 | 行政がその後に動いたことを、自分の提案の「成果」と言い切らないでください。「その後の市の動き」などとして、事実と出典を分けて記録します |

## 困ったときの順番

1. **AIに聞く** — [困ったときのプロンプト](docs/困ったときのプロンプト.md)をAIに貼り、秘密情報や個人情報を隠したスクリーンショットを渡す
2. **手順書をAIに読ませる** — このリポジトリの手順書を添付して、「次にやることを1つだけ教えて」と頼む
3. **過去の質問を探す** — [Discussions](../../discussions)を検索する
4. **公開で質問する** — それでも解決しないときは、Discussionsの「Q&A」にフォームに沿って投稿する

**個別の連絡（LINE、メール、SNSのDMなど）での質問には回答しません。**  
公開の場で解決すれば、同じことで困る次の人の助けになるためです。

## 公開Q&Aのルール

- 質問は[Discussionsの「Q&A」](../../discussions/categories/q-a)へ投稿してください
- 回答は保証しません。有志が参加者同士で答え合う場です。AIで解決できた方法も共有してください
- **投稿禁止：** 個人情報、市民からの相談内容、非公開資料、パスワード、APIキー、トークン、会議録の原文・全文・大量の本文断片
- スクリーンショットは、氏名・メールアドレス・ファイル名なども含め、公開してよい情報だけが写っているか確認してください
- 手順書の誤りや、スターターキットで再現できる不具合は[Issues](../../issues)へ投稿してください
- 特定の政党・会派の主張を行う場ではありません
